# Music assets

Drop one royalty-licensed track per mood here, named `<mood>.mp3`:
`upbeat.mp3`, `ambient.mp3`, `cinematic.mp3`, `corporate.mp3`. A missing
track is skipped at mix time (narration + SFX only), so rendering still
works before assets are supplied.

These files are never served to end users -- they may only leave the system
baked into a rendered MP4 (licensing requirement, see CLAUDE.md).
